# Navbook PM

_A lightweight software project manager that lives inside your git repo._

Navbook is a ticket system that stores its entire state as plaintext files inside the repository. Does your PR close a ticket? Just update the ticket's status and add this change to your branch.

This is meant to replace your code forge's issues with a portable, decentralised, offline-first solution. Is GitHub down? No big deal, you'll push your comment to `origin` whenever it's available again.
