Self-review (`/code-review high`) of revision 1 found six minor issues. All are fixed in revision 2:

- **The link led nowhere with a merged or closed filter.** The every-branch scan finds open pull requests only, so the link is now shown only when the status filter lets an open one through.
- **The switch and the link built the same address twice.** One helper now builds both, and it also keeps the URL fragment, which the link used to drop.
- **The `empty-all-refs` test ID was unused.** It has been removed.
- **The description slot sits in a paragraph.** Its doc comment now says it takes inline content only, and that block content goes in `empty-actions`.
- **Two behaviours were untested.** One test now checks that the link does not grow history. A new test checks that there is no link with the switch on or with `status=merged`. Both fail on a build without `replace` and without the guard.

Biome, `nuxi typecheck`, vitest (426) and the full web e2e suite (174) pass on revision 2.
