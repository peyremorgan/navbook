A third first-party plugin, `@navbook/plugin-chat` (#c43a2w7e, branch `feat/s86nic83-plugin-chat`), is packed by the API image too. It imports `@navbook/cli/plugin` and `@navbook/server/plugin` for types only, so its `prepack` has plugin-kb's needs: its own dependencies installed, and `packages/cli` copied as sources. Its branch copies its manifest and sources and packs it, but leaves the install filter as `dev` has it. Whichever lands after this fix (7f2a40b) adds `--filter "@navbook/plugin-chat..."`, as plugin-tests will.
