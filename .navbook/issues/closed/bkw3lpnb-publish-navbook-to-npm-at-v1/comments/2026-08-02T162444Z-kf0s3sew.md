Everything that can be automated is done: the tag-triggered release workflow is in .github/workflows/release.yml, it refuses to publish unless the tag matches the package version, and it runs the conformance suite against the built package before `npm publish`.

What remains is not code. Publishing needs an NPM_TOKEN in the repository secrets and a human deciding the moment, so this stays open until someone tags v1.0.0.

Verified locally in the meantime: `npm pack` produces a 135-file tarball, and installing it into a scratch project gives a working `nav` on PATH.
