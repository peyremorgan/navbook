One change to the run format agreed in planning: a run also carries `steps`, the number of steps its plan had when it started. Without it, a tool holding only the run file (a `nav pr list --all-refs` scan, a forge's file view, the `tested:` term) could not tell a complete run from an incomplete one, because the plan is not in the pull request's directory. `plan-sha` still pins the exact text, and `nav doctor` warns when the two disagree. Starting a run also writes the plan's blob into the object store, so `plan-sha` resolves even when the plan was edited and not yet committed.
