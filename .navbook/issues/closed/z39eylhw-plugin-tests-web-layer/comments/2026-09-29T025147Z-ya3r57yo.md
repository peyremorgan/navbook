Done in afc00b2 on `feat/z9yqtsbv-plugin-tests`.

- **Pages:** `/tests` lists plans with their latest outcome and pass rate. A plan's page shows its steps and run history, with Edit and Run. A run's page shows each plan step at `plan-sha` beside its status, actual result and attachments.
- **Plan editor:** structured fields; the server composes `plan.md`. A stale save keeps the draft and shows the plan as it is now.
- **Runner:** answers are kept in the browser per run until **Save progress** or **Finish** commits them. A stale save refetches and keeps the draft. Attachments upload through `attachToTestRun`.
- **Pull requests:** a test runs panel with Record a run (refused with the branch named when the server does not serve it), a tested badge on rows, and a `tested` filter.
- **Host:** `PrRow` renders row badges with `where="pr"`, as `IssueRow` does. The web build, the e2e stack and the dev stack load both plugins. The fixture seeds plan `slow-sign-in`, a finished passed run on the served PR and an open standalone run.

Tests: plugin-tests unit 109 passed (9 web helpers), web vitest 410 passed, Playwright 178 passed (9 in the plugin project).
