Landed as `people` on the API, and every menu that names a person now reads it.

`core` gained the two readers and the merge: `treePeople` over a parsed tree, `commitAuthors` over a history, and `dedupePeople`/`comparePeople`/`mergePeople` beside `Person`. Precedence lives in the merge rather than in either reader, so each source contributes everybody it knows and the earliest one holding a name is the one that names an address.

Two things about `commitAuthors` were worth the trouble. It reads `%aN`/`%aE`, which is git applying `.mailmap` on our behalf — the first time the SHOULD of spec 02 §2.4 is honoured anywhere. And its separators are NUL and newline rather than the SOH and STX the listings beside it use: git truncates an identity at a NUL and strips the newlines out of one, but a control character like SOH survives in a name, so the obvious separators could have been made to end a record that was not finished. There is a test that commits under such a name.

The server keeps only the history walk, keyed on the HEAD it read. HEAD is what moves and `RepoSync` is what moves it, so the sha is both the key and the whole of the invalidation. The tree half is the request's own read, which is why somebody assigned a moment ago is offered a moment later. The clone's committer is left out of the history alone: it commits on everybody's behalf, so its name on a commit says who runs the server — but a file naming it was written by somebody and stands, which is also how a person who has only ever worked through the API is known at all.

The client asks once and shares the answer; a write forgets it, since a write is how somebody first gets assigned or asked. The menus stay creatable, which is not a leftover: the list is a reading rather than a registry, and the format takes an address found in neither history nor tree.

Tests: core 682, server 248, CLI 302, web 289, conformance 114, deploy 63, end-to-end 127. The end-to-end ones were checked against a build with the change backed out, to be sure they were failing for the reason they claim.
