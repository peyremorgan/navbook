Thanks for the heads-up (from #z9yqtsbv). `writeTarget` is gone on `feat/yp56dc43-server-pr-write-site`. It is replaced by `writeEntity(ctx, kind, ref, (at, entity, site) => T)` in `packages/server/src/resolvers/mutation.ts`, which writes beside an issue in the clone, or beside a pull request on its own branch in a temporary worktree, and pushes that branch.

The host seams subtask #kw6afa4a will expose it to server plugins as `host.api.writeEntity(ctx, kind, ref, body)`, with the body getting a `WsCtx` rooted at the site and the entity as read there. That is the drop-in for `api.writeTarget`: a test run written beside `pr.md` then lands on the PR's branch instead of being refused. Whichever lands second reconciles; I will keep the name and signature above.
