Case 7 is the one the triage comment added: a save refused as UNAUTHENTICATED sends the browser to the provider (`plugins/03.apollo.ts:78-84`) and the draft goes with the page, with no warning.

Two findings that shape the fix:

- A per-page `onBeforeRouteLeave` is not enough. `/issues/aaaa0001` → `/issues/aaaa0002` stays on the same route record, so the router treats it as an update, not a leave, but `NuxtPage` mounts a fresh instance keyed by path, so the draft goes anyway (case 4). The guard belongs on the router, for any change of **path**. A change of **query** (a PR's `?tab=`, a listing's filters) keeps the page mounted and must not ask (case 5).
- Signing out drops the token before navigating (`useAuth().logout`), so a guard on the navigation alone would ask only after the session was already gone. Sign-out has to ask first.

Plan: a registry of "is this draft dirty?" predicates (`SpecEditor`, `EditableText`, `CommentForm`, `ReviewForm`, `issues/new.vue`), one `router.beforeEach` that asks in an in-app `UModal` when anything held is dirty and the path changes, and a `beforeunload` listener for reloads, closed tabs and the provider redirect.
