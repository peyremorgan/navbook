Confirmed on `dev` (8688f86), end to end against a built bundle.

## Repro

1. Open `/prs` with the switch off and a filter that only a fetched branch can
   satisfy. In the e2e fixture, the unserved pull request's own ID does it:
   `/prs?q=bbbb0002`.
2. The empty state appears. Its accessibility tree is two plain paragraphs,
   with nothing to click:

   ```
   - paragraph: No pull requests match this filter
   - paragraph: Nothing on this checkout matches. A pull request lives on its own branch — try every fetched branch.
   ```

3. The only way to act on the suggestion is the `switch "Every fetched branch"`
   at the top right of the page.

A new Playwright case in `packages/web/test-e2e/pull-requests.spec.ts` asserts
the link, and fails on the current bundle:

```
✘ [web] › test-e2e/pull-requests.spec.ts:45:1 › offers every fetched branch from an empty listing (21.1s)
  TimeoutError: locator.click: Timeout 20000ms exceeded.
  - waiting for getByRole('link', { name: 'try every fetched branch' })
```

The empty-state assertion just before it passes, so the page is in the right
state. Only the link is missing.

## Where it comes from

`packages/web/app/pages/prs/index.vue` hands the sentence to `QueryState` as a
string prop:

```vue
<QueryState
  ...
  empty-title="No pull requests match this filter"
  :empty-description="
    allRefs
      ? 'Nothing on any fetched branch matches.'
      : 'Nothing on this checkout matches. A pull request lives on its own branch — try every fetched branch.'
  "
>
```

`packages/web/app/components/QueryState.vue` interpolates it as text, so no
markup can get in:

```vue
<p class="mt-1 text-sm text-muted">{{ emptyDescription ?? "No entries match this view." }}</p>
<slot name="empty-actions" />
```

The switch itself is a computed over `route.query.refs`, written with
`router.replace`. So a link to the same route with `refs=all` added to the
current query sets the switch and reruns the search, keeping the filter.

## Proposed fix

- Wrap the description in a `QueryState` slot that defaults to the prop, so the
  page can put markup in it.
- On `/prs`, render "try every fetched branch" as a `ULink` to the current
  query plus `refs=all`, with `replace` like the switch.
