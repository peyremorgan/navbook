Implemented on `feat/kw6afa4a-plugin-host-seams`, stacked on #yp56dc43's branch (four commits).

- **Server:** `host.api.execute(ctx, document, variables)` runs an operation against the served schema as the viewer, with parsed and validated documents cached. `host.api.schema()` exposes the composed schema once every plugin has activated. `host.api.writeEntity` is the write site `addComment` uses: a pull request is written on its own branch. The server probe exercises all three.
- **CLI:** `nav pr open --source <branch> [-y]` writes the pull request on another local branch, in its clean worktree or a temporary one. `ui.withPrWriteSite` and `ui.withBranchWriteSite` are on `CliPluginUi`. The `pr-elsewhere` module is imported only at plugin activation, so an unused plugin still costs a listing nothing.
- **Web:** an `overlays` slot rendered by the default layout; `startStack({ pluginPaths, env })`.
- **Docs:** spec 04 §4.4 (network) and `pr open`, README, doc/plugins.md.
