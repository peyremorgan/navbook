A second first-party plugin, `@navbook/plugin-tests` (#z9yqtsbv), is packed by the API image on `feat/z9yqtsbv-plugin-tests`. Its `prepack` has the same needs as plugin-kb's: its own dependencies installed, and `packages/cli` copied as sources.

Whichever of the two branches lands second adds `--filter "@navbook/plugin-tests..."` to the build stage's `pnpm install`. With that line and this fix (7f2a40b) applied to the plugin-tests branch, both images build with `NAVBOOK_PLUGINS="@navbook/plugin-kb @navbook/plugin-tests"`. The API image loads both plugins, and against a signed token it served `testPlans`, finished a run with `saveTestRun` and pushed it, and round-tripped an attachment. The web bundle has the `/tests` pages.
