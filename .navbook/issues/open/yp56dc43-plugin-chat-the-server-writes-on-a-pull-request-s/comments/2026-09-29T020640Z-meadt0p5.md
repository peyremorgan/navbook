Implemented on `feat/yp56dc43-server-pr-write-site` (two commits).

- `RepoSync.writeOn` runs the write transaction on a site of the caller's choosing. It merges the site with its remote-tracking branch, and pushes that branch with the same one-retry rule as the served branch.
- `write-site.ts` makes a temporary worktree on a local copy of `origin/<branch>`. The copy is deleted once the remote has everything on it, and kept while it carries an unpushed commit. Leftovers from a killed server are swept at startup.
- `openPr(input: OpenPrInput!)`. A target known only as `origin/<target>` is read from the remote-tracking branch (core `preparePrOpen` gained `source` and `targetRev`).
- `addComment` / `updatePr` on a PR held by another branch now write there. The rare refusal (branch not on the remote, or held by a foreign worktree) is PRECONDITION with `extensions.branch`, which the web alert reads.
