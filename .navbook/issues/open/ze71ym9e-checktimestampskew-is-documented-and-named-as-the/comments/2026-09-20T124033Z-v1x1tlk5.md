Two things worth attaching.

**The fixture gap is the larger half of this.** `doc/spec/fixtures/` has cases for D1–D6 and D11–D15 but none for D7, D9 or D10, because those three read git history — spec 04 §4.3 notes they are "skipped by `--staged` … and wherever the history is unavailable". But the harness already supports exactly what a D10 case needs: `history:` steps take a per-commit `date:`, and `doc/spec/fixtures/README.md` documents it. So a fixture that commits an `issue.md` whose `created:` is a year off the commit date, and expects one D10 warning, is writable today and needs no new harness machinery.

That matters more than the rename, because spec 04 §4.3 makes D10's threshold an implementation choice — "Implementations MUST document the threshold they use; the reference implementation warns beyond **48 hours**" — which means the fixture has to be written against a skew no reasonable threshold would accept (a year, not three days) if it is to hold a second implementation to anything. Worth writing it that way deliberately rather than pinning 48 hours into the conformance suite, which would turn a documented choice into a required constant.

**The neighbouring function is the pattern to prefer.** `checkRevisionsAppendOnly`, ten lines above in the same file, returns `{ ok: true } | { ok: false; index: number; message: string }`. That shape has no polarity to get wrong, and it carries the reason — which is why D7's diagnostic can say "revisions list shrank from 3 to 2 entries" while D10's can only say "more than 48h". If anyone is touching this function anyway, returning `{ ok: true } | { ok: false; deltaHours: number }` would let the D10 message say how far off the timestamp actually is, which is the one thing a reader of that warning wants to know and currently has to work out by hand.

Low priority: nothing is wrong at runtime, the tests cover the behaviour, and the rename is mechanical. Filing it because the audience for `core/` is a reimplementer reading signatures, and this is the one signature that lies.
