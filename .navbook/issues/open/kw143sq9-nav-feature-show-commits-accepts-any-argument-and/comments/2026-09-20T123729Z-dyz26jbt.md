There is a better place to put this than the command body, and it is in a library we already depend on.

Commander's documented pattern for exactly this is to throw `InvalidArgumentError` from the custom parser, which it catches and turns into its own usage error — so the value never reaches the command at all, and the message appears with the standard `error:` prefix and help footer rather than as a `nav:` line:

```ts
import { InvalidArgumentError } from "commander";

/** A whole number of things, refused at parse time rather than in the command. */
function wholeNumber(what: string) {
  return (value: string): number => {
    const parsed = Number(value);
    if (!Number.isInteger(parsed) || parsed < 0) {
      throw new InvalidArgumentError(`${what} takes a whole number`);
    }
    return parsed;
  };
}
```

`InvalidArgumentError` replaced the deprecated `InvalidOptionArgumentError` and works for both option-arguments and command-arguments, so one helper covers `--commits`, `--depth`, `--rank` (which wants `Number.isFinite` rather than `isInteger`) and `-n/--count`. That would also remove the reason the current parsers return `Number.NaN` for a blank value — a sentinel that only exists so the command can spot it later, which is the shape this issue is about.

Two caveats before anyone reaches for it:

1. **`--rank` genuinely cannot be refused at parse time alone.** Spec 02 §2.5 allows "any finite decimal … negative values included", so its check is `Number.isFinite`, not the integer one — and `rank: 0` must survive, which is why the code carefully asks "was one given" rather than "is it truthy". Any shared helper has to keep those apart.
2. **The four flags do not want the same message.** `nav: --depth takes a whole number of levels` names the unit, and that is worth keeping; a generic "takes a whole number" reads worse. The helper should take the noun, as sketched above.

The regression test is one line beside the existing `--depth` case in `packages/cli/test/cli/feature.test.ts`, which already covers `--commits 0`.
