### Open points for the implementation
- **Single-host Ingress:** `packages/web/docker/config.sh` writes `NAVBOOK_GRAPHQL_URL` into `config.json` as-is (`"graphqlUrl": "$graphql_url"`). I have not checked whether the client accepts a path on its own host (`/graphql`) as well as a full URL. The example should prove this with a test.
- **PID 1:** a pod has no equivalent of `init: true`, so the zombie fix in #rcsql1v9 should go into the image (`tini` in `ENTRYPOINT`). Otherwise the Kubernetes API pod accumulates zombie git processes too.
- **fsGroup:** the image `chown`s `/srv/navbook` to `node` (uid 1000) and runs as `USER node`. A fresh Longhorn PVC mounts owned by root, so `securityContext.fsGroup: 1000` is required, as the issue says.
